# data/

ナゾトキマーケット2026 の出展団体・商品・会場配置のデータ。非公式の個人用。正確な情報は公式サイトと各団体の告知で確かめること。

## ファイル

| ファイル | 中身 | 作り方 |
|---|---|---|
| `raw/YYYY-MM-DD/` | 公式 TSV（booth.tsv・product.tsv）の取得日ごとの原本と、前回との差分 `diff.md`。再配布しないためリポジトリには入れず、手元にだけ置く | `npm run fetch-official` |
| `venue-layout.json` | 会場マップのブース矩形・入口・出口・入れ替わりブース。座標は公式マップ画像のピクセル | マップ画像から計測して手で作成（下記） |
| `booth-code-overrides.json` | マップの団体名と booth.tsv の団体名が自動で対応しないものの手動対応 | 手で編集 |
| `shards/*.json` | 団体ごとの収集結果（公式商品への追記・公式以外の商品・候補） | 収集作業で作成 |
| `booths.json` | 出展団体 | `npm run build-data` |
| `products.json` | 商品 | `npm run build-data` |
| `candidates.json` | 今回の出品と言い切れない候補（去年の出品・通販のみ等）。ツールには出さない | `npm run build-data` |
| `COVERAGE.md` | 収集のカバー率 | `npm run build-data` |

型の定義は `src/types.ts`。

## 値のルール

- すべての商品に出典（`sources`: URL と取得日）を1件以上付ける
- 取れなかった値は `null` にし、項目名を `unconfirmed` に入れる（`priceNote`・`limited` は「特記なし」と区別できないので対象外）
- 価格は円・税込の整数
- 画像は URL を参照するだけで、リポジトリに保存しない。X の画像は `https://pbs.twimg.com/media/<ID>?format=jpg&name=small` の形（形式の指定が無いと 404 になる）
- ハッシュタグ（`hashtags`）は、団体・商品の今回向けの告知（2026年9月以降の X の投稿）に出てきたタグだけを、`#` を外して投稿どおりの表記で入れ、出典の投稿を付ける。団体全体のタグは団体に、特定の商品だけのタグはその商品に入れる。宣伝と関係ない一般語（#拡散希望 など）や別イベント向けのタグは入れない

## 難易度（`difficulty`）

5段階。`source` で出どころを区別する。

- `official`: 公式・団体の表記を5段階に換算したもの。換算のしかたを `basis` に書く
  - 「★★★★☆」「4/5」→ そのまま 4
  - 3段階の表記（★★☆ など）→ 5段階に比例換算して四捨五入（2/3 → 3.3 → 3）
  - 言葉の表記 → 低い=2・普通=3・高い=4・最高難度=5
- `estimated`: 表記が無いものを、説明文・対象・所要時間から推定したもの。根拠を `basis` に1文で書く
- `unknown`: 推定の根拠が弱いもの。`level` は `null`

推定の基準:

| level | 目安 |
|---|---|
| 1 | 初心者・子ども向け。「初めての方でも」「お子さまと」など |
| 2 | やさしめ。短時間・ライトと書かれている |
| 3 | 標準。謎解き好き向けの普通の難易度、所要60〜120分程度 |
| 4 | 難しめ。「歯ごたえ」「結構難しい」、長時間 |
| 5 | 上級者向けの高難度パズル。「玄人」「超高難易度」「最高難度」 |

## カテゴリ（`category`）

| 値 | 意味 |
|---|---|
| `kit` | 持ち帰り謎キット（封筒・箱・紙もので家で遊ぶもの） |
| `booklet` | 冊子（謎解き本・問題集・小説） |
| `online` | スマホ・Web謎（主にスマホ・PC・LINE上で遊ぶもの） |
| `goods` | グッズ（アクキー・文具など。謎付きグッズを含む） |
| `other` | その他（ボードゲーム・その場で遊ぶ体験など） |

## 会場マップ（`venue-layout.json`）の作り方

公式マップ画像（`https://www.scrapmagazine.com/s/nazomarket/img/top/map_2026.jpg`、2000×1413px）から作った。

1. 列ごとのブース色（例: A 列は濃い青、Cc 列は赤茶）に近い画素を拾い、縦横の投影でブースの矩形を計測した（94ブース）。番号は画像の表記どおり右（入口側）から 1, 2, …
2. 計測した矩形を画像に重ねて、全ブースの位置と番号が画像と一致することを目で確かめた
3. 団体名は画像の凡例から書き起こした。Cc6・Cc7・Ce5 は土曜と日曜で団体が入れ替わる（Ce5 は日曜は出展なし）
4. 入口・出口・協賛ブース・宅配ブース・トイレの位置は画像から読み取った概略値

公式の注記どおり、実際のレイアウトとは異なる場合がある。マップ画像が更新されたら（`fetch-official` の差分にハッシュの変化が出る）計測し直す。
