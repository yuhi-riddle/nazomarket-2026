# ナゾトキマーケット2026 買い物メモ（非公式）

ナゾトキマーケット2026（2026-11-07 土・11-08 日、東京ドームシティ プリズムホール）で何を買うかを決めるための、個人用の Web ツールです。

**非公式です。** 主催・出展団体とは関係ありません。商品・価格は公式サイトと各団体の告知（X・HP）で確かめられたものだけを載せ、出典の URL と取得日を商品ごとに残しています。最新の正確な情報は公式サイトと各団体の告知で確かめてください。団体のロゴや商品画像はこのリポジトリに保存せず、元のサイトの URL を参照して表示しています。

## できること

| タブ | 内容 |
|---|---|
| 一覧 | 価格・難易度・カテゴリ・エリア・タグ・キーワードで絞り込み、価格順・難易度順などで並べ替え。推定の難易度には「推定」と出す |
| リスト | 「絶対／できれば／余裕があれば」の3段階で入れた商品の合計（絶対だけ・できれば込み・全部）と予算の残り。価格不明の件数は別に数える。テキストでコピーできる |
| マップ | 会場マップにリストのブースを優先度の色で表示。ブースを押すと商品が出る。回る順番（優先度ごと、入口から近い順）を線と番号で表示 |
| 傾向・おすすめ | 価格・カテゴリ・難易度・新作の分布、好み（予算・難易度・カテゴリ・遊び方）からのおすすめ上位10件と点数の理由、好みに合う商品が多いエリア |
| 当日 | 買ったら印を付けて、使った金額・残り予算・購入点数を見る。ナゾコレの「何点で1回」を入れると残りの点数を出す |

画面上部で行く日（土・日）を選ぶと、マップ・回る順番・当日・おすすめがその日の出展に合わせて変わります。選んだ内容はブラウザ（localStorage）にだけ保存され、どこにも送信されません。

## 動かし方

Node.js 24 以上が必要です。

```bash
npm install
```

```bash
npm run dev
```

表示された URL（例 `http://localhost:5173/`）をブラウザで開きます。

ほかのコマンド:

| コマンド | 内容 |
|---|---|
| `npm test` | テスト（ロジック・データの検証・データ組み立てスクリプト） |
| `npm run typecheck` | 型チェック |
| `npm run build` | `dist/` に静的ファイルを書き出す（相対パスなので、どこに置いても開ける） |
| `npm run preview` | 書き出したものをローカルで確認 |

## 公式データを取り直して反映する

公式の出展者・商品データは更新されることがあります。取り直すときは次の順に進めます（開催前日の 11/6 にも行う予定）。

1. 公式データを取得する。`data/raw/<今日の日付>/` に原本と、前回との差分 `diff.md` が保存されます

   ```bash
   npm run fetch-official
   ```

2. 差分を確認する。`data/raw/<今日の日付>/diff.md` を開き、増えた・消えた・値が変わった団体と商品を見ます。会場マップ画像が変わったときも、ここに書かれます

3. 必要なら収集結果を直す。公式の値（団体名・商品名・価格など）は次の手順で自動で入れ直されるので、手で直すのは次のときだけです
   - 団体が増えた・ブースが変わった: `data/venue-layout.json`（マップが変わったとき）や `data/booth-code-overrides.json`（名前が自動で対応しないとき）
   - 公式以外の情報（X・HP で見つけた商品や追記）を足す・直す: `data/shards/*.json`

4. データを組み立て直して検証する。団体とブースが対応しないと止まり、理由が表示されます

   ```bash
   npm run build-data
   ```

   ```bash
   npm test
   ```

5. `data/COVERAGE.md` で収集のカバー率を確かめ、`npm run build` で書き出します

データの形と値のルール（「推定」の付け方、取れなかった値の扱いなど）は [data/README.md](data/README.md) にあります。

## 作り

- Vite + TypeScript（フレームワークなし）。地図とグラフは SVG を自前で描いています
- データ（`data/*.json`）はビルド時に取り込むので、サーバーもログインも要りません
- 公式データの取得は `scripts/fetch-official.ts`、データの組み立ては `scripts/build-data.ts`。取得するのは公式の TSV 2つとマップ画像（ハッシュ値の比較だけ）の3つで、間は1秒あけます
